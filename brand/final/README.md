# OpenConvert mole icon

## Current master

`openconvert-mole-folder.svg` is the current app-icon master. It replaces the
ambiguous tunnel/hat with a recognizable two-layer, tabbed file folder. The
mole retains the source character's sweeping back and cheek lines, bright eye,
long snout, whiskers, and three-digit paws, but has no surrounding hole. Both
paws curl over the front folder lip. Its entire nose is verdigris and has two
charcoal nostrils.

`openconvert-mole-monoline-traced.svg` remains the faithful tunnel-based trace for
comparison. `openconvert-mole-file-opening.svg` remains the earlier flat-document
composition.

## Folder composition

Rendered checks are in `previews/folder-1024.png`, `previews/folder-128.png`,
and `previews/folder-32.png`.

Production-oriented modern-minimal mole icon, designed directly as SVG.

- `openconvert-mole-app-icon.svg` — 512 × 512 desktop application source.
- `openconvert-mole-favicon.svg` — optically simplified 32 × 32 version.
- `openconvert-mole-mark.svg` — standalone circular brand mark.

The mole communicates local/private work and passage. The circular tunnel keeps
the earlier Route idea without adding a literal arrow. The face uses a small
muted-pink nose as a recognition anchor; it is the only non-system accent.

Do not scale the desktop artwork down to favicon size. Use the dedicated
favicon, which removes the paws, mouth, highlight, and inner tunnel colour.

## Earlier manual monoline revision (superseded)

- `openconvert-mole-monoline-app-icon.svg` follows the selected Mole 04 concept.
- `openconvert-mole-monoline-favicon.svg` is its small-size redraw.

The original split-colour ring is replaced with one complete verdigris tunnel,
so colour describes a real object. The nested arcs over the head are replaced
with a single back-to-head contour, removing the accidental hat silhouette.

The earlier hand-redrawn monoline revision is retained for comparison only. It
is superseded by `openconvert-mole-monoline-traced.svg`.
