# OpenConvert logo package

All assets in this folder are generated from `openconvert-mole-logo.svg`, the
approved folder-and-mole master.

## Website

- `website/logo.svg` — responsive primary logo.
- `website/favicon.svg` — scalable favicon source.
- `website/favicon.ico` — multi-size browser/Windows favicon.
- `website/favicon-16.png`, `favicon-32.png`, `favicon-48.png` — browser sizes.
- `website/favicon-180.png` — Apple touch icon size.
- `website/favicon-192.png`, `favicon-512.png` — PWA icon sizes.
- `website/logo-1200.png` — raster logo for general web use.
- `website/og-image.png` — social/share preview raster.

## Desktop application

- `desktop/app-icon.svg` — vector source for platforms that support SVG.
- `desktop/app-icon.ico` — Windows multi-resolution icon.
- `desktop/app-icon.icns` — macOS multi-resolution icon.
- `desktop/app-icon-1024.png` through `app-icon-16.png` — standard raster sizes
  for Windows, macOS, Linux, installers, and taskbars.

The source artwork preserves its original aspect ratio. Square raster assets use
an off-white contain treatment so no part of the logo is cropped.
